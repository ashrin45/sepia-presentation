# SEPIA — Présentation

Présentation HTML statique du projet **SEPIA** (Sepsis Early Prediction by Intelligence Artificielle), étude pilote 2026 du laboratoire d'hématologie du CHI André Grégoire.

Trois modules :
- **01 · Vue d'ensemble** — pour cliniciens et chefs de service
- **02 · Pipeline technique** — pour data managers, biostat, DSI
- **03 · Cadre réglementaire** — pour URC, CNIL, DPO et comités éthiques

Le site est généré statiquement à partir du sous-arbre `docs/presentation/sepia/` du repo de travail `ashrin45/Nano_Warehouse` (privé). Ce repo public est un mirroir, déployé via GitHub Pages.

**Porteur** : Dr Ahmed Ashrin · CHI André Grégoire.
